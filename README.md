# app-policies

Privacy policies for the Android apps published by CodeOrbit Labs, served as
GitHub Pages at https://varun9358.github.io/app-policies/

Each app has one Markdown file; Jekyll renders it to `<slug>.html`. The Play
Console listing for each app points at its own page, and every app also links
to it from its Settings screen, because Google requires the policy to be
reachable both in the store listing and inside the app.

To update a policy, edit its `.md` file and push to `main` — Pages rebuilds
automatically. Change the "Last updated" date at the top when the substance
changes.
